

## cambiar colores

abrir el archivo **`css/styles.css`**. al principio en la seccion `:root` donde estan todas las variables de color:

```css
:root {
  /* Fondo general exterior de la pantalla */
  --color-beige-body: #f4efe6;

  /* Fondo cálido del papel de la invitación */
  --color-paper-light: #faf7f0;

  /* Fondo de las tarjetas individuales (iglesia, fiesta, regalos) */
  --color-card-bg: #fdfbf7;

  /* Tono dorado principal */
  --color-gold: #c5a059;

  /* Tono dorado intenso para textos */
  --color-gold-deep: #96732a;

  /* Color de los textos principales */
  --color-text-main: #3a332a;

  /* Color de los textos secundarios */
  --color-text-muted: #736758;
}
```

### 💡 Ejemplos de personalización de color:
* **Si quieres un beige más rosado / nude:** cambia `--color-paper-light` a `#faf4ee`.
* **Si quieres un beige más arena / lino:** cambia `--color-beige-body` a `#ece4d6`.
* **Si quieres un dorado más brillante o amarillo:** cambia `--color-gold` a `#d4af37`.
